# Ostentum

Source code of [Ostentum](https://www.curseforge.com/minecraft/mc-mods/ostentum), a vanilla expansion built on
Fundamentum: summoning saddles, grappling hooks, summon charms, trick weapons, whips, special moons, a Pillager Siege
night and boss relics. Most of it is Fundamentum data under `data/ostentum/fundamentum/`.

Each Minecraft version is its own Gradle project. Build one with `./gradlew build` inside its folder. Requires
Fundamentum and Curios; Patchouli is optional.
